# Tomo Keisan App（とも けいさん）

小学1〜3年生むけの、ブラウザで動く算数れんしゅうアプリです。

## できること

- 1〜3年のレベルをえらぶ
- もんだい数（10/20/30）をえらぶ
- たしざん / ひきざん / かけざん / わりざん をえらぶ
- 100点まんてん（正答率）でスコア表示
- まちがえた問題のふりかえり

## つかいかた

1. フォルダ内の `index.html` をブラウザでひらく（メニュー）
2. すきなモードをえらぶ

ローカルで開くだけで動きます（インストール不要）。

## ページ

- `time-attack-addsub.html` ① たし算/ひき算（45もん）
- `time-attack-kuku.html` ② 九九（45もん）
- `time-attack-mix-add-kuku.html` ③ たし算 + 九九（45もん）
- `time-attack-column-2digit.html` ④ 2けたの筆算（45もん、答えは10の位/1の位で入力）
- `practice.html` れんしゅう（ふつうモード）

## ファイル

- `index.html` メニュー
- `styles.css` デザイン
- `app.js` もんだい生成・採点ロジック
- `common.js` タイムアタック共通ユーティリティ
